토요일 농구팀 **리버스(REVERSE)** 의 누적 승률·주간 경기 결과를 폰에서 보기 좋게 정리한 단일 HTML 페이지입니다.

## 🔒 팀원 전용 (입장 코드)

이 페이지는 **입장 코드로 잠겨** 있습니다. 코드를 넣어야만 화면이 열립니다.

- 팀 데이터(선수 이름·전적)는 `index.html` 안에 **암호문(`ENC_DATA`)으로만** 들어 있습니다.
  입장 코드로만 풀리는 **AES-256-CTR + HMAC-SHA256** 암호문이며, 키는 코드에서 **PBKDF2-SHA256**(10만 회)으로 유도합니다.
  → 저장소 소스를 봐도 선수 이름·전적은 평문으로 보이지 않습니다.
- 한 번 입장한 브라우저는 `localStorage`에 기억되어 다음 접속부터 자동으로 열립니다.
  공용 PC 등에서 다시 잠그려면 브라우저의 이 사이트 데이터(저장소)를 지우세요.
- 입장 코드를 **2번 이상 틀리면** `제한된 공간입니다. 관리자에게 입장코드를 문의해 주세요.` 로 안내합니다(탐색 세션 동안 유지).
- 게이트 카드 상단에 리버스 로고를, 하단에 팀원 안심용 3줄 안내(검색 차단 · 암호화 보호 · 관리자 반영)를 표시합니다.
- 검색엔진 차단: 루트 `robots.txt`(`Disallow: /`) + `<meta name="robots" content="noindex, nofollow">`.
- `crypto.subtle`(Web Crypto)을 못 쓰는 인앱 브라우저에서도 열리도록, 같은 결과를 내는 순수 JS 복호화 구현이 페이지 안에 함께 들어 있습니다.

0. **🔮 예정 경기 프리뷰** — 주차 선택 목록의 맨 위 항목(`2026-11-28 (예정 · 9주차 프리뷰)`).
   경기 결과 카드 자리에 3개 팀 **명단·팀장(👑)·평균 승률·예상 순위·예상 성적**이 표시됩니다.
   아직 치르지 않은 경기이므로 **누적 승률·순위·상단 요약(8주 · 24경기)은 2026-11-21 8주차 확정 기준** 그대로입니다.
   결과가 반영되면 같은 프리뷰가 **그 주차 카드/이력 안에 보존**되어 실제 결과와 **순위 적중·우승 적중**으로 비교됩니다.
   **정본(데이터) 프리뷰**가 있으면 기기에 등록하지 않아도 카드 안의 **`🏀 경기 진행하기` · `✏️ 수정하기`** 로 바로 이어집니다 — 편집 창도 정본 인원으로 채워서 열립니다.
1. **주차 선택 바(상단 고정)** — `‹` / 날짜 드롭다운 / `›` / `최신`. 확정 주차를 고르면 그 주차 경기 결과와 **그 주차까지의 누적 승률·순위·팀장 전적·게스트**로 화면 전체가 바뀝니다.
2. **바로가기 탭** — 경기 결과 / 승률 순위 / 로스터 / 주간 전체로 바로 이동합니다.
3. **경기 결과** — 선택 주차의 우승팀, 3팀 전적·팀장, 스코어, 팀 명단·특이사항 (경기 전 예상이 있으면 비교 한 줄)
4. **최종 승률** — 정규 순위(참여율 40%↑), 순위 외(정규 진입 조건), 👑 팀장 전적(**컴팩트 리스트**), 👥 게스트
5. **로스터** — 정회원 24명의 **등번호·신장·포지션·구분(정규 / 순위 외 / 미출전)** 을 한 화면에. 포지션 필터·검색을 함께 씁니다.
6. **주간 결과 전체** — 최신 주차부터 8주 아코디언 (🔮 프리뷰가 있는 주차는 `프리뷰 비교` 표시)

선수 이름을 검색하거나 누르면 개인 전적 카드(승률·출전·전적·팀장 전적·주차별 상대/스코어)가 뜨고, 카드에는 **정회원 / 게스트** 구분 배지가 표시됩니다.
로스터(`basketball/reverse-roster.md`)에 등록된 선수는 카드 상단에 **등번호·신장·포지션**(`#24 · 181cm · SF/PF`)이 함께 표시됩니다.

### ✏️ 개인 상세정보 입력·업데이트 (정회원 · 게스트)

카드 안에서 **키(cm)·넘버(없음 선택 가능)·포지션(PG/SG/SF/PF/C, 복수 선택)** 을 직접 입력할 수 있습니다.

- **정보가 비어 있는 정회원**: 카드를 열면 `개인 상세정보를 입력해 주세요` 폼이 바로 펼쳐집니다. `다음에 하기` 를 누르면 접히고 **`정보 입력하기`** 버튼만 남아 전적을 편하게 볼 수 있습니다.
- **정보가 이미 있는 정회원**: 배지만 깔끔히 보이고, **`개인정보 업데이트하기`** 버튼으로 폼을 엽니다.
- **게스트**: 폼이 자동으로 펼쳐지지 않습니다. 카드에는 **`정보 입력하기`**(등록 전) 또는 **`개인정보 업데이트하기`**(등록 후) 버튼만 보이고, 눌렀을 때 입력 폼이 열립니다.
- `저장 및 카톡 복사` 를 누르면 **이 기기(localStorage)에만 임시 저장**되어 카드 배지에 즉시 반영되고, 아래 양식이 클립보드에 복사됩니다(인앱 브라우저에서 자동 복사가 막혀도 화면의 텍스트 박스에서 직접 복사 가능).

```
리버스 정보 업데이트 요청 드립니다.
[김영익 / 181cm / 24번 / SF/PF]
```

> ※ 입력 내용은 **현재 기기에만 임시 적용**됩니다. 복사한 양식을 **리버스 카톡방(관리자)에 전달**해야 `basketball/reverse-roster.md` → 재빌드로 전체 페이지에 최종 반영됩니다.

상단 요약 카드 4개는 **`승률` · `경기` · `정회원` · `게스트`** 순서이고, 눌러서 이동합니다 — `승률`은 승률 순위, `경기`는 경기 결과, `정회원`은 **로스터 정보**, `게스트`는 게스트 목록(접혀 있으면 먼저 펼침)으로 이동합니다.

## 🏀 경기 진행하기 (실전 기록지)

매치 프리뷰 카드의 **`🏀 경기 진행하기`** 나 이력 항목의 같은 버튼으로 엽니다. 한 화면을 그대로 쓰는 전체 화면 보드입니다.

- **상단 바는 한 줄** — `🏀 날짜 (요일) · 3파전 경기 진행` + **`⚙️ 설정`** + **`⛶ 전체화면`** + **`✕ 닫기`**.
- **📱 세로 모드 안내 토스트** — 세로(innerHeight > innerWidth)로 열거나 세로로 돌리면 `📱 가로 모드에 최적화되어 있습니다 (화면을 가로로 돌려 보세요)` 가 **3.5초간** 뜨고 자동으로 사라집니다. 가로로 돌리면 남은 시간과 관계없이 **즉시 숨김**, 다시 세로로 돌리면 다시 뜹니다. 화면 높이를 차지하지 않고(`position:fixed`·`pointer-events:none`) 조작을 막지 않습니다.
- **`⚙️ 설정` 시트** — 🌓 테마(어두운 · **중간** · 밝은) · 🔎 글씨 크기(작게/보통/**크게** — 기본값 크게) · 🔆 화면꺼짐 방지 · 쿼터(1~3Q/1~4Q) · 경기 수(2파전) · 🖨️ A4 인쇄 · 📸 사진 저장 · ✏️ 매치 프리뷰 수정 · 🧩 매치 프리뷰 초기화(서버 정본 복원) · 🔄 전체 초기화(확인 팝업).
  설정을 바꿔도 시트는 열린 채로 유지됩니다.
- **테마 3단계** — `어두운`(기본) · `중간`(순백색 없이 차분한 소프트 슬레이트, 배경 `#dce3ec`) · `밝은`(순백색 대신 살짝 낮춘 오프화이트, 배경 `#f1f4f8`). 사진 저장(PNG)에도 선택한 테마가 그대로 반영됩니다.
- **가로(전체화면)는 좌우 2단** — 왼쪽 점수표 + 팀 순위 요약(약 59%) / 오른쪽 팀별 명단(3파전 3열 / 2파전 2열, 약 41%).
  세로 화면은 같은 내용을 위아래로 쌓아 **세로 스크롤 없이 `100dvh` 안에** 들어가도록 배율을 자동으로 맞춥니다(화면을 넘길 때만 그 패널만 스크롤).
  글씨 크기는 “화면을 얼마나 채울지”로 동작합니다 — 작게 84% · 보통 꽉 채움 · 크게 꽉 채움(가로에서는 자리가 남으면 최대 1.7배까지 확대해 화면을 채움). 기본값은 **크게**입니다.
- **명단은 종이 기록지형 표** — 왼쪽 `번` 열(1~6) + 팀별 열. 각 줄에서 `⚿` 드래그로 순서 변경, 3파전은 `n회` 를 눌러 휴식 횟수를 0→1→2→3→0으로 바꾸고, 팀 머리의 **`순서`** 로 휴식 순서를 지정합니다.
- **정본 매치 프리뷰 우선** — 이미 경기 결과가 확정된 주차는 기기에 임시 등록한 프리뷰가 있더라도 **서버 정본(`data.json`) 프리뷰 기준**으로 이력·주간 결과·경기 진행 초기값을 표시합니다(예정 날짜만 기기 등록분 우선). 기기 등록분은 `⚙️ 설정 → 🧩 매치 프리뷰 초기화 (서버 정본 복원)`으로 지우고 정본으로 되돌릴 수 있습니다.
- **2파전 점수표는 경기(행) × 쿼터(열) 한 표** — 각 칸에 그 쿼터에 쉬는 번호(`휴식 2·3`)가 함께 표시됩니다.
- 점수 입력·합계·누적·팀 순위는 입력 즉시 다시 계산되고, A4 인쇄는 흑백 기록지로, 📸 사진 저장은 PNG 파일로 내려줍니다.

## ⚖️ 팀 구성 추천하기 (3파전·2파전 밸런스 배정)

상단 요약 칸 아래 한 줄을 **좌우 1:1 두 칸**으로 나눴습니다 — 왼쪽 **`🤝 짝꿍 승률 계산하기`**, 오른쪽 파란 **`⚖️ 팀 구성 추천하기`**(390px 에서도 한 줄·줄넘김 없음).

- **방식과 팀 이름**: `3파전` → **화이트 · 블랙 · 형광**, `2파전` → **화이트 · 블랙**(안내·결과 카드 모두 이 순서). 3파전 최소 **15명**(3팀 × 5명), 2파전 최소 **10명**(2팀 × 5명) — 5대5 경기 기준입니다.
- **참석 인원**: 칩 목록에서 **정회원 24명 · 게스트 18명**을 고릅니다(최대 30명). 열면 정회원 전체가 선택된 상태로 시작하고 `정회원 전체` / `선택 초기화`·이름 검색·포지션 필터·`게스트 포함` 토글로 조정합니다.
- **가상 선수(시트 안에서 바로)**: 참석 인원 영역의 **`+ 가상 선수 추가`** 로 이름(8자)·포지션(복수)·가정 승률(0~100%)·가정 표본(1~30경기)을 넣으면 **저장과 동시에 참석 인원에 체크**되어 팀 구성에 바로 반영됩니다. 목록에서 누르면 선택/해제, `✎` 수정, `🗑` 삭제. 저장소(`localStorage: reverse-fake-players-v1`)를 짝꿍 시트와 공유해 **양쪽 목록이 함께 바뀝니다**.
- **밸런스 기준**: **`현재 승률 기반`**(8주 누적 승률) / **`개인 스탯 기반`**. 리버스는 **개인 스탯 원본이 없어** 스탯 기반을 고르면 `이 사이트에는 개인 스탯 원본이 없어 현재 승률 기준으로 계산합니다` 안내를 띄우고 승률 기준으로 계산합니다.
- **배정 방식**: 기준 점수 내림차순 **스네이크 초안** → 같은 인원 팀끼리 1:1 교환을 반복해 **팀 평균 편차·포지션 분산·에이스 분산·짝꿍 상성**을 함께 점수화한 비용을 최소화합니다(6회 재시작). 포지션 미등록자는 포지션 균형 계산에서 제외하고 인원만 맞춥니다.
- **결과 화면**: 팀 카드마다 **팀 이름·인원·평균 승률·포지션 구성**(가드/포워드/센터, 복수 포지션·미등록 수)·**선수별 승률**·최고/최저 승률을 표시하고, 아래 **`왜 이렇게 나눴나`** 에 ① 팀 평균과 최대 편차 ② 포지션 배분 ③ 상위 3인 분산 ④ 짝꿍 상성(가장 높은 동반 승률 짝, 팀별 동반 승률 범위) ⑤ 무출전 선수 처리 를 설명합니다.
- **인원 규칙**: 팀 인원은 **±1명 이내**(예: 24명 → 8·8·8). 인원이 최소(3파전 15명·2파전 10명) 미만이면 배정을 진행하지 않고 `최소 15명 이상 선택해야 3파전 팀 구성이 가능합니다 (현재 N명 · M명 더 필요)` 처럼 안내합니다.
- **개인정보**: 계산은 브라우저 안에서만 하고 결과를 외부로 보내지 않습니다.

## 매주 갱신 방법

데이터 원본은 **`src/data.json`**(평문, 저장소에는 올리지 않음 — `.gitignore`)이고, 빌드하면 암호화되어 `index.html` 에 들어갑니다.
`index.html` 은 빌드 산출물이므로 **직접 고치지 마세요**(다음 빌드에서 덮어써집니다).

0. **팀원 정보(등번호·신장·포지션)** — `../basketball/reverse-roster.md` 의 표(`| 이름 | 신장 | 등번호 | 포지션 | 비고 |`)에 선수를 추가하면 `src/build_data.py` 가 읽어 각 선수의 `number`·`height`·`position` 필드를 `data.json` 에 넣고, 개인 전적 카드에 `#24 · 181cm · SF/PF` 처럼, **로스터 탭**에 등번호·신장·포지션·구분이 표시됩니다. **키·번호·포지션이 비어 있어도 로스터에서 빠지지 않습니다**(오류 아님). 포지션은 `PG / SG / SF / PF / C` 만 인정하며 `SF/PF` 처럼 복수 표기도 됩니다.
   - **정회원 총원** = `정규 순위 + 순위 외 + 미출전 정회원`(현재 24명). 상단 `정회원` 칸·로스터 요약·**짝꿍 승률 계산기 후보**가 이 값을 씁니다. 포지션 정보가 없는 선수도 짝꿍 계산기에 모두 나옵니다.
1. `src/data.json` 의 `weeks` 배열에 새 주차 추가 — `date`, `title`, `venue`, `standings`, `games`, `rosters`, `note`
   - 결과지가 아직 없는 주차는 `{ "date": "2026-09-26", "noSheet": true }` 로 넣으면 화면에 **"원본 결과지 보완 예정"** 으로 표시됩니다.
2. **`PREVIEWS`** (`src/build_data.py`) — 주차별 매치 프리뷰를 **목록으로 쌓습니다**(팀 명단·팀장·평균 승률·예상 성적).
   - 결과지가 **없는** 가장 마지막 날짜는 `data.preview` 가 되어 화면 `경기 결과` 자리에 표시됩니다.
   - 결과지가 **들어온** 날짜의 프리뷰는 그 주차 카드에 `preview` 로 붙어 **주간 결과 이력에 보존**되고 실제 결과와 비교됩니다. 지난 항목은 지우지 마세요(비교 이력).
   - `preview` 는 누적 승률·순위 집계에 포함되지 않습니다.
3. `members`(정규)·`outsiders`(순위 외)·`guests`(게스트)는 **최종 주차 공식 기록** — `weeks`·`att`·`w`·`l`·`rate` 갱신 (`att` = `weeks / criteria.totalWeeks * 100`)
4. `criteria.totalWeeks`, `period` 갱신
5. **암호화 빌드** — 입장 코드를 넣어 실행하면 `src/data.enc.json` 갱신 + `index.html` 재생성

```bash
# 결과지 마크다운(basketball/reverse-records.md, reverse-guests.md)에서 src/data.json 재생성 + 검증 (선택)
python3 src/build_data.py

# data.json -> 암호화 -> index.html  (입장 코드는 프롬프트로 입력)
python3 src/build_site.py
#   또는:  python3 src/build_site.py --code ****   /  REVERSE_CODE=**** python3 src/build_site.py
#   data.json 이 바뀌면 자동 재암호화, 강제로 하려면 --reencrypt
```

`build_site.py` 는 빌드 전에 **그 코드로 복호화되는지 검증**하고 주차·인원 요약을 출력합니다. 코드가 틀리면 `입장 코드가 데이터와 맞지 않습니다` 로 멈춥니다.

`build_data.py` 는 주차별 로스터로 개인 전적을 다시 계산해 기록지 표와 대조합니다(불일치 시 출력).

## 구조

```
index.html         배포 페이지 (단일 파일 · 잠금 화면 + ENC_DATA 암호문)
robots.txt         검색엔진 전체 차단
src/template.html  페이지 템플릿 (잠금·복호화 코드 포함)

src/data.enc.json  DATA 암호문 (index.html 에 들어가는 값)
src/build_*.py     데이터 추출·검증 및 암호화 빌드 스크립트
```
