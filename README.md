# 🏀 REVERSE · 리버스 승률 &amp; 주간 결과

토요일 농구팀 **리버스(REVERSE)** 의 누적 승률·주간 경기 결과를 폰에서 보기 좋게 정리한 단일 HTML 페이지입니다.

- 🌐 **https://youngik-kim.github.io/reverse-basketball/**
- 🏟 구장: 부천JW스포츠센터 · 매주 토요일 3파전(팀당 2경기)
- 📅 집계 기간: 2026-10-03 ~ 2026-11-21 (8주 · 24경기)

## 🔒 팀원 전용 (입장 코드)

이 페이지는 **입장 코드로 잠겨** 있습니다. 코드를 넣어야만 화면이 열립니다.

- 팀 데이터(선수 이름·전적)는 `index.html` 안에 **암호문(`ENC_DATA`)으로만** 들어 있습니다.
  입장 코드로만 풀리는 **AES-256-CTR + HMAC-SHA256** 암호문이며, 키는 코드에서 **PBKDF2-SHA256**(10만 회)으로 유도합니다.
  → 저장소 소스를 봐도 선수 이름·전적은 평문으로 보이지 않습니다.
- 한 번 입장한 브라우저는 `localStorage`에 기억되어 다음 접속부터 자동으로 열립니다.
  공용 PC 등에서 다시 잠그려면 브라우저의 이 사이트 데이터(저장소)를 지우세요.
- 입장 코드를 **2번 이상 틀리면** `제한된 공간입니다. 관리자에게 입장코드를 문의해 주세요.` 로 안내합니다(탐색 세션 동안 유지).
- 게이트 카드 상단에 리버스 로고를, 하단에 팀원 안심용 3줄 안내(검색 차단 · 암호화 보호 · 관리자 반영)를 표시합니다.
- 검색엔진 차단: 루트 `robots.txt`(`Disallow: /`) + `<meta name="robots" content="noindex, nofollow">`.
- `crypto.subtle`(Web Crypto)을 못 쓰는 인앱 브라우저에서도 열리도록, 같은 결과를 내는 순수 JS 복호화 구현이 페이지 안에 함께 들어 있습니다.

## 화면 구성

첫 화면에서 **이번 주 예정 경기(매치 프리뷰)** 와 **최종 승률(정규 순위)** 을 함께 볼 수 있습니다.

0. **🔮 예정 경기 프리뷰** — 주차 선택 목록의 맨 위 항목(`2026-11-28 (예정 · 9주차 프리뷰)`).
   경기 결과 카드 자리에 3개 팀 **명단·팀장(👑)·평균 승률·예상 성적**이 표시됩니다.
   아직 치르지 않은 경기이므로 **누적 승률·순위·상단 요약(8주 · 15명 · 24경기)은 2026-11-21 8주차 확정 기준** 그대로입니다.
1. **주차 선택 바(상단 고정)** — `‹` / 날짜 드롭다운 / `›` / `최신`. 확정 주차를 고르면 그 주차 경기 결과와 **그 주차까지의 누적 승률·순위·팀장 전적·게스트**로 화면 전체가 바뀝니다.
2. **경기 결과** — 선택 주차의 우승팀, 3팀 전적·팀장, 스코어, 팀 명단·특이사항
3. **최종 승률** — 정규 순위(참여율 40%↑), 순위 외(정규 진입 조건), 👑 팀장 전적, 🔥 개근, 👥 게스트
4. **주간 결과 전체** — 최신 주차부터 8주 아코디언

선수 이름을 검색하거나 누르면 개인 전적 카드(승률·출전·전적·팀장 전적·주차별 상대/스코어)가 뜹니다.
로스터(`basketball/reverse-roster.md`)에 등록된 선수는 카드 상단에 **등번호·신장·포지션**(`#24 · 181cm · SF/PF`)이 함께 표시됩니다.

### ✏️ 개인 상세정보 입력·업데이트 (정회원 · 게스트)

카드 안에서 **키(cm)·넘버(없음 선택 가능)·포지션(PG/SG/SF/PF/C, 복수 선택)** 을 직접 입력할 수 있습니다.

- **정보가 비어 있는 정회원**: 카드를 열면 `개인 상세정보를 입력해 주세요` 폼이 바로 펼쳐집니다. `다음에 하기` 를 누르면 접히고 **`정보 입력하기`** 버튼만 남아 전적을 편하게 볼 수 있습니다.
- **정보가 이미 있는 정회원**: 배지만 깔끔히 보이고, **`개인정보 업데이트하기`** 버튼으로 폼을 엽니다.
- **게스트**: 폼이 자동으로 펼쳐지지 않습니다. 카드에는 **`정보 입력하기`**(등록 전) 또는 **`개인정보 업데이트하기`**(등록 후) 버튼만 보이고, 눌렀을 때 입력 폼이 열립니다.
- `저장 및 카톡 복사` 를 누르면 **이 기기(localStorage)에만 임시 저장**되어 카드 배지에 즉시 반영되고, 아래 양식이 클립보드에 복사됩니다(인앱 브라우저에서 자동 복사가 막혀도 화면의 텍스트 박스에서 직접 복사 가능).

```
리버스 정보 업데이트 요청 드립니다.
[김영익 / 181cm / 24번 / SF/PF]
```

> ※ 입력 내용은 **현재 기기에만 임시 적용**됩니다. 복사한 양식을 **리버스 카톡방(관리자)에 전달**해야 `basketball/reverse-roster.md` → 재빌드로 전체 페이지에 최종 반영됩니다.

상단 요약 카드 4개(`정규`·`경기`·`게스트`·`최고 승률`)는 눌러서 이동합니다 — 정규/경기/게스트는 해당 섹션으로 부드럽게 스크롤(게스트는 접혀 있으면 먼저 펼침), `최고 승률`은 그 주차 1위 선수의 개인 전적 카드를 바로 엽니다.

히어로의 **`🏀 SATURDAY · 부천JW스포츠센터`** 배지를 누르면 구장 길찾기 시트가 열립니다.

- 구장명·주소(`경기 부천시 오정구 석천로442번길 19`)와 **`주소 복사`** 버튼
- 길찾기 앱 선택: **네이버지도 · 카카오맵 · 티맵(TMAP)**

  - PC: 네이버·카카오는 웹 지도(새 탭), 티맵은 모바일 전용 안내

정규 순위 커트라인은 그때까지 진행된 주차의 40%(올림)이며, 최종 8주에서는 기록지 기준과 같은 **4주**가 됩니다. 최종 주차 화면의 값은 기록지 표와 전건 일치합니다.

## 매주 갱신 방법

데이터 원본은 **`src/data.json`**(평문, 저장소에는 올리지 않음 — `.gitignore`)이고, 빌드하면 암호화되어 `index.html` 에 들어갑니다.
`index.html` 은 빌드 산출물이므로 **직접 고치지 마세요**(다음 빌드에서 덮어써집니다).

0. **팀원 정보(등번호·신장·포지션)** — `../basketball/reverse-roster.md` 의 표(`| 이름 | 신장 | 등번호 | 포지션 | 비고 |`)에 선수를 추가하면 `src/build_data.py` 가 읽어 각 선수의 `number`·`height`·`position` 필드를 `data.json` 에 넣고, 개인 전적 카드에 `#24 · 181cm · SF/PF` 처럼 표시됩니다. **등록되지 않은 선수는 필드가 없어 표시되지 않습니다**(오류 아님). 포지션은 `PG / SG / SF / PF / C` 만 인정하며 `SF/PF` 처럼 복수 표기도 됩니다.
1. `src/data.json` 의 `weeks` 배열에 새 주차 추가 — `date`, `title`, `venue`, `standings`, `games`, `rosters`, `note`
   - 결과지가 아직 없는 주차는 `{ "date": "2026-09-26", "noSheet": true }` 로 넣으면 화면에 **"원본 결과지 보완 예정"** 으로 표시됩니다.
2. `preview` — 다음 주차 예정 경기(팀 명단·팀장·평균 승률·예상 성적). 명단이 확정될 때마다 `src/build_data.py` 의 `PREVIEW` 블록을 그 주차로 교체합니다.
   `preview` 는 누적 승률·순위 집계에 포함되지 않습니다.
3. `members`(정규)·`outsiders`(순위 외)·`guests`(게스트)는 **최종 주차 공식 기록** — `weeks`·`att`·`w`·`l`·`rate` 갱신 (`att` = `weeks / criteria.totalWeeks * 100`)
4. `criteria.totalWeeks`, `period` 갱신
5. **암호화 빌드** — 입장 코드를 넣어 실행하면 `src/data.enc.json` 갱신 + `index.html` 재생성

```bash
# 결과지 마크다운(basketball/reverse-records.md, reverse-guests.md)에서 src/data.json 재생성 + 검증 (선택)
python3 src/build_data.py

# data.json -> 암호화 -> index.html  (입장 코드는 프롬프트로 입력)
python3 src/build_site.py
#   또는:  python3 src/build_site.py --code ****   /  REVERSE_CODE=**** python3 src/build_site.py
#   data.json 이 바뀌면 자동 재암호화, 강제로 하려면 --reencrypt
```

`build_site.py` 는 빌드 전에 **그 코드로 복호화되는지 검증**하고 주차·인원 요약을 출력합니다. 코드가 틀리면 `입장 코드가 데이터와 맞지 않습니다` 로 멈춥니다.

`build_data.py` 는 주차별 로스터로 개인 전적을 다시 계산해 기록지 표와 대조합니다(불일치 시 출력).

## 구조

```
index.html         배포 페이지 (단일 파일 · 잠금 화면 + ENC_DATA 암호문)
robots.txt         검색엔진 전체 차단
src/template.html  페이지 템플릿 (잠금·복호화 코드 포함)
src/data.json      DATA 평문 원본 (git 제외 — 로컬 전용)
src/data.enc.json  DATA 암호문 (index.html 에 들어가는 값)
src/build_*.py     데이터 추출·검증 및 암호화 빌드 스크립트
```

> ⚠️ 암호문은 공개 저장소에 있으므로, 코드를 아는 사람은 누구나 열 수 있습니다. 코드는 팀 내부에서만 공유하세요.
> 저장소의 **과거 커밋**에는 예전 평문 데이터가 남아 있을 수 있습니다(이력 재작성 전까지).
